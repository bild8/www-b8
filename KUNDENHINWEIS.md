# Kundenhinweis zur Ablage von Logos und Brand Assets

Stand: 2026-05-23

Diese kurze Einschaetzung dient der Kenntnisnahme durch Kunden und ersetzt keine
individuelle Rechtsberatung.

Dieses Repository ist oeffentlich einsehbar und wird zur technischen
Auslieferung von Assets verwendet, insbesondere ueber GitHub Pages. In einem
oeffentlichen GitHub-Repository koennen Inhalte von Dritten angesehen und im
Rahmen der GitHub-Funktionen geforkt werden. GitHub weist ausserdem darauf hin,
dass Inhalte nur eingestellt werden duerfen, wenn die einstellende Partei hierzu
berechtigt ist.

Logos, Marken, Icons, Namen, Bildzeichen, Corporate-Identity-Dateien und
sonstige Brand Assets koennen urheberrechtlich, markenrechtlich,
designrechtlich oder durch sonstige Rechte geschuetzt sein. Die im Repository
enthaltene restriktive Lizenz- und Rechteerklaerung untersagt Dritten eine
Nutzung ohne Einwilligung. Sie ersetzt aber nicht die erforderliche
Berechtigung, fremde Logos oder Brand Assets in dieses oeffentliche Repository
hochzuladen, dort vorzuhalten und ueber GitHub Pages auszuliefern.

Deshalb duerfen in diesem Repository nur solche Logos, Marken, Icons und
sonstigen Brand Assets abgelegt werden, fuer die eine entsprechende Vereinbarung
mit software8 besteht. Diese Vereinbarung muss die oeffentliche technische
Speicherung und Auslieferung der Assets, insbesondere ueber GitHub und GitHub
Pages, abdecken.

Vor der Ablage eines Kundenlogos oder sonstigen Kunden-Assets muss daher
sichergestellt sein:

- Der Kunde oder Rechteinhaber hat software8 die erforderlichen Rechte
  eingeraeumt.
- Die Nutzung umfasst Speicherung, Veroeffentlichung und technische Auslieferung
  ueber dieses oeffentliche Repository und GitHub Pages.
- Die Nutzung ist auf den vereinbarten Zweck beschraenkt, etwa die Darstellung
  auf von software8 betriebenen oder betreuten Webseiten, Apps oder Diensten.
- Etwaige Brand Guidelines, Widerrufsrechte, Laufzeiten und Loeschpflichten sind
  dokumentiert.

Ohne eine solche Vereinbarung duerfen Kundenlogos und sonstige fremde Brand
Assets nicht in diesem Repository abgelegt oder ueber dieses Repository
ausgeliefert werden.
